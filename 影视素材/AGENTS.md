# 影视素材整理规范

本目录用于保存电视剧图片和原始下载压缩包。以后新增、下载或整理影视素材时，沿用以下规则。

## 存放位置

```text
影视素材/
├─ 韩剧/
│  └─ 剧名/
│     ├─ 海报/
│     ├─ 剧照/
│     ├─ 拼图/
│     ├─ 花絮/
│     └─ 重复文件/
├─ 国产剧/
│  └─ 剧名/（同上）
├─ 原始压缩包/
├─ 文件对照表.csv
└─ AGENTS.md
```

- 使用中文剧名，与已有目录保持一致；新增剧集先检查是否已有同名或别名目录。
- 图片直接放进对应剧名和图片类型目录，不再在项目根目录新建剧名文件夹。
- 只有存在对应文件时才创建类型目录，不必为每部剧创建所有空目录。
- 无法确认剧名或图片类型的文件放到本目录的“待分类”，确认后再归档。
- 带剧名的宣传图片归入“海报”；单幅场景图片归入“剧照”；多幅拼接图归入“拼图”；幕后照片归入“花絮”。

## 文件命名

格式：`剧名_类型_方向_宽x高_三位序号.原扩展名`

示例：`雀骨_海报_竖版_680x1000_001.jpg`

- 方向使用“横版”“竖版”或“方图”；分辨率读取文件实际像素，不能凭预览猜测。
- 序号在同一剧名、同一图片类型内递增；添加新文件时不要重新编号已有文件。
- 原样保留图片格式和内容，不通过更换扩展名转换格式，不为了整理压缩或重绘图片。
- 需要区分不同海报设计时，可以在类型后增加简短描述，例如 `雀骨_海报_红衣大婚_竖版_1500x2667_002.jpg`。
- 官网标识、来源水印、是否使用 AI 等信息，仅在已核实时记录，不能根据文件名或视觉效果作出确定判断。

## 保留原始信息

- `文件对照表.csv` 记录本次整理的原路径、新路径、剧名、类型、像素和 SHA256，便于找回原文件名和核对文件内容。
- 后续整理或重命名时补充对照表记录；已知来源链接可添加“来源”列，不编造来源。
- 完全重复的文件放到对应剧名的“重复文件”，未经用户要求不删除。
- 原始压缩包集中放入“原始压缩包”，保留原文件名；不能确认所属剧集时，不依据日期强行归入某部剧。
- 搬运前检查目标是否存在；遇到同名文件先核对，不能覆盖。整理后核对数量和文件内容。
