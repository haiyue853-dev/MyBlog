- 数据库草稿可刷新或换设备继续；浏览器临时草稿只暂存在当前标签页，关闭标签页后不保证保留。
- 编辑窗口不因点击外侧关闭，未保存关闭时弹出继续编辑、放弃修改或保留草稿的中央确认框。
- 浏览无需署名，首次评论时只填昵称；公开文章支持留言、本人删除留言和站主回复。
- 留言管理支持已读／未读、分页、原留言定位、删除及回复，继承文章权限。
- 回收站可恢复内容、图片关联、留言、回复和点赞；永久删除需要确认。
- 资料柜支持上传、下载、分类、搜索、删除和未使用图片清理；上传不自动公开私人附件。
- 备份中心支持生成、列出、下载完整 `.tar.gz` 备份，包含数据库、附件和恢复说明。
- 备份恢复、附件字节一致性、Node／D1 权限和迁移已有回归验证。

### 1.5 后端与保留模块

- 单站主登录、会话续期、写入来源检查、登录限流、Node API 和 SQLite 持久化已实现。
- 提供 Docker Compose + Caddy 部署文件，保留 Cloudflare Workers + D1 + R2 适配及迁移脚本。
- Iris 页面、会话、流式回答、知识库与资料导入接口已实现，**仅站主本人可用**。访客菜单隐藏入口，未登录直接打开 `/?view=iris` 显示主页；全部 Iris 接口要求有效站主会话，Cloudflare 未配置服务时也先验证登录。退出登录后原会话无法再调用 Iris。
- Iris 网页新增“让 Iris 帮我写博客”：选择文章或日常，输入文字、上传最多 10 份图片／文档，整理成预览后进入现有编辑器修改、保存草稿或确认发布。生成本身不写入博客、不公开附件；文档不随文章公开，候选及编辑在当前标签页可恢复。失败重试保留当前确认的正文、封面和公开范围，不重复创建。**只修改博客源码，调用 Iris 已有接口。**
- Iris 是独立服务，博客不会自动启动它；2026-10-06 检查本机 8000 端口没有监听，未验收真实模型对话。代理权限测试使用隔离数据库和本地模拟服务，不调用计费模型。
- **旅行地图和视频作品已按用户要求撤下**，没有活跃栏目入口，旧栏目地址回到主页；组件、数据及必要备份兼容代码保留，未来可恢复。

数据以 `Item` 为核心：日常、文章与观后感使用 `kind: moment`，通过可选 `article` 区分文章；小卡与影视使用 `kind: collection`，通过可选 `watch` 区分影视。影视功能没有另建一套数据库，留言、回复、回收站和统计另有各自的表。

Node 注入 `Store`，Cloudflare 注入 `CloudStore`，通过 `withRuntime` 复用多数业务接口。**两套前端并不完全等价**：Node 支持独立文章页、地图、时光轴和完整备份中心；Cloudflare 静态客户端没有开启完整文章模式，Worker 未接入 Node 备份中心接口。

默认持久化位置：`data/world.sqlite`、`data/files/`、`data/backups/`。迁移以完整备份或一致性快照为依据，不覆盖仍在运行的数据库。
