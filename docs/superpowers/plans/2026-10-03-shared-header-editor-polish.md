# 统一头部与编辑体验实现计划

**目标：** 全部正常页面沿用小屋头部，阅读文章只切换下方；字号使用现有主题菜单；未保存时关闭弹出确认；普通段落缩进不变成代码块。

**方案：** 各 Next 路由统一进入 Space，阅读器作为下方内容嵌入；站内文章链接与浏览器历史同步，保留鉴权与直接访问。复用 ThemeSelect 和 Modal。仅将 Markdown 的缩进代码节点按段落重解析，显式围栏代码继续保留。

- [x] Space 与独立路由统一，文章阅读、前后篇、地图筛选和导航原位切换。
- [x] 字号菜单、未保存确认弹窗、正文缩进展示修复；追加用户要求的代码块输入按钮，保留缩进，自动选择不会被粘贴反引号截断的围栏。
- [x] 类型检查、相关及全套测试、构建；隔离数据检查头部、手机、字号选择与关闭确认。
