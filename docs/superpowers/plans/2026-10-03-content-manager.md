# 站主内容管理中心实现计划

**目标：** 登录后统一管理日常、文章、观后感，支持标题／分类／日期／可见性／草稿筛选、继续编辑、发布与首页置顶。

**架构：** 在现有 Space 中增加仅站主可进入的管理栏目，保留主导航；使用原编辑器与 items API。记录 JSON 增加可选 status、pinned、writingType，旧记录默认已发布，旧观后感根据分类识别。草稿独立于公开范围，服务端同时保护记录、附件、点赞与统计；本地 SQLite 和 D1 使用同一发布条件。

**技术栈：** Next.js 16、React、TypeScript、SQLite／D1、现有 CSS 与 Lucide 图标。

**约定：** 不改动用户现有内容；不添加依赖；不提交或部署。草稿默认仅站主可读，发布后按所选可见范围展示；置顶仅用于已发布文章／观后感。日期筛选使用创建日期，排序可选最近创建或最近修改。

**本轮界面补充：** 将内容管理、资料柜、Iris、小屋统计折叠到头部“小屋工具”；管理筛选与行内可见范围使用主题菜单，支持键盘与外侧收起；修正搜索框重复边框。
