# 留言管理

用户已确认开始。入口为「小屋工具 → 内容管理 → 留言」，延续奶油色和粉色主题，不增加头部入口。

1. 新访客留言默认未读，站主留言不计入未读；已读状态持久化，随数据库备份与迁移保存。
2. 仅登录站主能查看跨文章的留言列表，包含昵称、内容、时间、所属文章。支持全部／未读、分页、刷新、标记已读／未读。
3. 「查看原留言」在保留公共头部的文章页面定位对应留言，支持二十条以后的留言，随后标记已读。
4. 删除前展示主题确认框；删除同步清除已读记录，权限和原有访客评论行为保持一致。
