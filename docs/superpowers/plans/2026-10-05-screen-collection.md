# 收藏馆影视片单实现计划

**目标：** 参考 yaronluo.com/bangumi 的海报墙与观看筛选，为韩剧、电影、国产电视剧等提供可管理的片单，保留原小卡。

**方案：** 收藏馆内部切换“小卡收藏／影视片单”，不新增头部导航。现有 collection JSON 添加可选 watch 配置，无数据库迁移；共享 Node／D1 items API 进行校验。沿用 Editor 上传、未保存提示与草稿，关联观后感只显示当前用户可见内容。

**文件：** types.ts、watch-collection.ts、api/items.ts、editor-draft.ts、watch-fields.tsx、editor.tsx、watch-library.tsx、space.tsx、watch-library.css、globals.css、tests/watch-collection.test.ts。
