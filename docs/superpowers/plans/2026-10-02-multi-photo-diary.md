# 多图日记实现计划

> 在当前会话使用 executing-plans 内联执行。保留工作区已有改动，不提交或发布。

**目标：** 生活碎片支持最多 12 张照片、多选上传、封面选择、拖动与按钮排序、详情大图切换；所有附图沿用记录可见范围。

**架构：** 在记录 JSON 中增加有序 `images`（assetId、width、height），保留 `assetId` 表示封面。旧单图记录自动按一张照片读取。复用现有上传接口、SQLite 存储和登录权限，不增加数据库服务或图片库依赖。收藏编辑保持单图。

**技术栈：** Next.js 16.3.8、React、TypeScript、SQLite、node:test。
