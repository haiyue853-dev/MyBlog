# 文章目录实现计划

**目标：** 按用户已确认的方案，将文章三级标题整理成可定位、随阅读高亮并可复制章节链接的目录；电脑正文旁展示，手机折叠，沿用现有头部与主题。

**方案：** 在现有 Markdown 渲染链中给标题生成稳定且唯一的章节 ID。目录读取正文实际渲染的标题，避免代码框或普通文字被误识别；滚动位置与头部尺寸决定当前章节与定位留白。正文仍存原始 Markdown，不改数据库。

- [x] 先写回归：标题与行内格式、重复标题、代码不进入目录、三级范围和默认正文不增加链接标记。
- [x] `src/lib/article-headings.ts` 负责 Markdown 标题 ID；RecordBody 只在文章阅读中启用，预览／日常保持原有行为。
- [x] `src/components/article-toc.tsx` 读取真实标题，支持定位、滚动高亮、复制当前文章章节链接、哈希直达与历史回退。
- [x] ArticleReader 引入正文与目录布局，文章头部／评论／前后篇沿用现有结构；响应式与减少动效适配。
- [x] 类型检查、测试与构建，隔离数据验证目录点击、滚动、重复标题、刷新直达、复制与手机折叠；正式数据不加入测试内容。
