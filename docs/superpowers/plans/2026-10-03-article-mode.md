# 生活碎片文章模式

用户确认在生活碎片中加入文章模式；收藏馆继续一图一卡。

- 编辑正文增加加粗、斜体、正文及三级标题、预览，与现有草稿一起保存。
- 文章沿用 moment 记录和多图附件，在 JSON 数据中增加可选文章配置：简短摘要、封面引导文字、剧透提示、封面位置、最多六条自由作品资料与一句摘录。不复制参考站内容，不改用户已有记录。
- 首页及生活列表只展示短摘要，文章通过独立 `/posts/[id]` 阅读页打开，包含封面标题、日期、字数及阅读时间、作品资料、全文和上一／下一篇。
- 旧日常继续现有图片和弹窗；文章阅读与相邻导航按公开权限筛选，私密文章只有站主可看；无图文章正常显示。
- 验证配置 API 持久化、私密访问及相邻文章筛选、摘要去掉排版符号、现有草稿兼容和新配置恢复；浏览器验收编辑、首页摘要、阅读布局、正文格式和导航。
- 用户进一步要求参考 yaronluo.com/series 的文章地图：新增 `/posts` 地图，按日常／工作／旅游／读后感及自定义分类、专题系列、内容标签筛选；同专题导航只连接该专题内可见文章。
- 最新调整：首页标题为“最近更新”，文章卡片与“最近的小事”简洁列表分开；文章打开独立阅读页，普通日常保留详情小窗口；新增 `/timeline` 按上海时区年月整理两种记录。新增文章草稿与新增日常草稿分别暂存。
