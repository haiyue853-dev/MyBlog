# 视频作品与旅行地图撤下

目标：撤下旅行地图展示，保留源代码和足迹数据；提供本地视频作品栏目，沿用共享头部和主题。

用户已选择上传本地视频并在网站内播放。设计采用封面卡片列表、标题／简介／分类筛选、点击播放；站主上传、编辑、公开／仅自己和移入回收站。无作品时展示真实空状态，不写入示例作品。

视频使用现有 items JSON 存储，新增 video 类型与独立视频附件字段，封面仍使用 assetId。既有账号、照片和旅行数据无需迁移。视频仅在公开已发布作品引用时可由访客读取，回收站保留附件。沿用完整备份。MP4／WebM 支持本地上传，单文件最多 100 MB；播放器支持分段读取和拖动进度。
