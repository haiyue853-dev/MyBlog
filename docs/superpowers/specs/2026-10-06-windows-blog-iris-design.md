# Windows 服务器上的博客与 Iris

用户已确认已有阿里云 Windows 服务器，Iris 仅本人使用、不修改 Iris 源码。沿用博客账号、先预览再发布。采用 Windows 原生 Node + Python + Caddy，避免要求更换系统或安装 Linux 容器。

博客仍在 MyBlog，Iris 源码仍在独立 Iris-agent。部署准备脚本只复制 server.py、requirements.txt 与 iris_agent 包到独立 iris-runtime，再放入博客维护的云端 agent.yaml。拒绝与源目录相互包含的目标，拒绝非空的首次目标，避免覆盖运行数据。更新由用户停服后复制同样代码文件；不覆盖 data、.env 或云配置。

博客及 Iris 分别绑定 127.0.0.1:3000、127.0.0.1:8000。Caddy 只代理博客，以真实域名提供 HTTPS。Caddy、博客、Iris 分别使用 WinSW 2.x 包装为 Windows 服务，采用 LocalService 账号、开机自启、失败重启与滚动日志。准备脚本只生成文件，不注册服务、改防火墙或部署云端。

环境文件独立保存模型密钥和网站来源，启动时验证变量并执行已有博客部署检查。Iris 首次启动关闭依赖本机 Ollama 的向量模型流水线，保留关键词知识库；云配置关闭语音、本机浏览器回退及消息网关。图片可作为配图，理解图片需要用户配置真正支持视觉的模型。长期数据在两个独立 data 目录，服务日志与证书另存。

验证：PowerShell 5.1/7 语法；隔离路径拒绝与准备脚本实跑；缺失密钥失败、首次种子不覆盖已有配置；复制后的真实 Iris 启动、健康、文档提取及重启后会话保留。当前没有 Docker，也无需它；实际 Windows 服务安装、云端 HTTPS 和模型生成由服务器验收，不把本地检查当作已部署。
