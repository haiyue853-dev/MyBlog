# 卡片每日点赞

用户希望卡片心心可以点击、记录总数，并让每位访客每天点一次。沿用原有心心位置和主题，不添加访客注册。

- 每位访客、每张卡片、每个北京时间自然日最多增加一次；再次点击不取消，次日可再点。
- 访客使用服务端签发的长期 HttpOnly Cookie 识别同一浏览器。数据库只保存标识摘要；换浏览器或清除 Cookie 会视为新访客，这不是实名人数统计。
- SQLite 和 Cloudflare D1 均持久化累计数、每位访客的最近点赞日期。数据库唯一约束和触发器完成原子更新，重复或并发请求不会重复计数。
- 公开卡片供访客点赞；私人卡片仅站主可读取和操作，跨站写请求拒绝。写操作按可信来源 IP 限制速率。
- 心心常驻显示累计数，今日已点显示实心；加载、提交期间不可重复点击，失败反馈错误，不伪造成功。切页、刷新及北京时间跨日重新读取状态。
- 增量部署命令编译代码，并在发布时执行幂等建表 SQL；只创建缺失的表和触发器，不导入本地账号或内容。这次只更新本地预览，照片及功能等待用户验收后再上传。

验证：两位访客、当日重复、并发、次日再次点赞、重启保留、私人范围、跨站拒绝、D1 工作运行时与浏览器可见计数。明确后续更新不需要 ZIP，也不使用首次初始化脚本。
