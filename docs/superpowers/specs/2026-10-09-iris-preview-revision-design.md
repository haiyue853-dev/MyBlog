# Iris 预览中继续改稿

用户在推荐“预览中继续改稿，保留原稿与图片，由本人确认发布”后回复“开始”，授权在既有博客中完成此功能。只实现此项，不扩展文章历史或写作偏好，不修改独立 Iris 源码，不部署或提交工作区。

在聊天整理与素材整理共用的 Editor 预览中提供修改要求输入、改稿／停止、恢复改稿前版本。要求基于当前手动修改过的内容；生成期间冻结编辑、上传、关闭与发布，停止后可继续操作。成功后显示新正文预览并同步当前候选；失败／取消不更改当前内容。保留最近一次改稿前完整编辑快照，允许恢复；当前标签页可以暂存此快照，保存或放弃时清除。

复用已有受站主身份与 Origin 保护的 iris/blog/prepare，在请求中增加 sourceDraft 分支，仅接受文字字段及当前照片编号。与原聊天回答／素材分支互斥，图片／文档不重复上传到 Iris，不启用工具或知识库。生成文字字段，不写博客数据库；客户端保留候选编号及所有非文字设置，明确保存才创建记录。

Markdown 中实际附加的图片节点及图片引用定义转为受保护占位符，模型必须原样保留。服务端核对每个占位符只出现一次且相对顺序不变，再恢复原始 Markdown 图片；遗漏、伪造图片或无效输出返回可重试错误，不破坏原稿。配图内容、尺寸、说明、引用形式与多处使用保持。

验证：新分支权限和输入边界、无工具／无知识库、无数据库写入、图片节点与引用定义保护、完整文字更新和其他设置保持、失败／停止／恢复／发布按钮状态；隔离浏览器从预览连续改稿，停止与失败不丢稿，恢复与明确发布，以及真实 Iris 一次虚构素材联调。完整测试、类型检查、构建后更新状态与账本。
