# 全站搜索

用户已批准四类内容搜索并要求开始，随后指定采用顶部栏正下方居中的小弹框。展开不切换页面和地址，不遮盖整页；空词只显示输入框，输入后显示紧凑分类筛选、结果数量和短摘要，结果在小框内滚动。点击文章进入现有阅读页，日常和收藏复用详情，收藏保持一图一卡。

复用按登录身份返回的 items，不新增接口、数据库或依赖。搜索函数先过滤可见范围，访客不显示私密和草稿，站主可以搜索两者。多词全部匹配，标题优先、分类标签其次、正文再次，再按时间和 ID 排序。摘要取正文命中附近，去掉图片配置及链接地址，文本通过 React 安全高亮。

当前会话关闭重开保留关键词和类型；刷新从当前正常页面开始。只显示一个叉：有文字时清空，无文字时关闭，也可点击外部或 Escape 收起。搜索框固定底色，不因点击分类或输入失焦变色，分类粉色选中。桌面宽度最多 600px；手机左右各留 18px，结果最大高度按头部及可视区域实时计算，含键盘缩小视口，避免超出屏幕。遵循既有动效开关。

验证搜索字段、多词、排序、摘要、四类识别、权限、文本转义和小弹框结构；浏览器验证居中、原页保留、单叉、分类底色、清空、无结果、20 条展开、详情和 Escape；隔离账号验证私密、观后感草稿与日常详情。
