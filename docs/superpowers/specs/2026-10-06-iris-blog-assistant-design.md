# Iris 网页博客助手

用户确认：仅在博客内发送素材，先预览、确认后发布；所有功能只修改 D:\MyBlog，不修改 Iris 源码。部署目标为阿里云。

在站主 Iris 页面增加“让 Iris 帮我写博客”面板，选择文章或日常，输入要求，上传最多 10 份图片／文档素材。图片使用博客上传与附件保存，文档留在私人资料柜。服务器读取选中的文件，通过 Iris 既有会话附件接口交给 Iris，再调用已有流式聊天接口生成结构化标题、Markdown 正文、分类、标签及摘要。

博客严格校验模型结果，只接受内容字段。模型不能决定发布状态、可见范围、附件身份或触发写入。生成成功仅返回预览，不创建博客条目。图片来自用户已选的博客文件；文档不会随文章公开。生成失败、取消、离线或不支持附件时显示错误，保留用户素材，不生成或发布半成品。

预览面板显示标题、正文和图片，提供“编辑并确认发布”。复用现有 Editor，增加助手预填入口和独立草稿键；用户可修改、保存草稿、选择公开／仅自己并发布。首次发布复用稳定 clientRequestId，避免重试重复创建。保存结果回传记录，显示草稿／发布状态与查看入口，并刷新父页面数据。

2026-10-06 用户补充：生成成功后自动弹出已有 Editor 确认窗口，正文默认以排版预览展示，可切回编辑、选择可见范围、保存草稿或点击确认发布。关闭窗口仍保留页面预览和重新打开入口；恢复暂存候选时不强制弹窗。只有成功且未取消的生成触发弹窗，取消、失败和离线不打开窗口，也不创建博客记录。普通编辑器继续默认编辑模式。

服务端仅向配置的 Iris 地址调用已存在接口，凭据仅服务器使用。新接口继承 requireOwner 与 requireOrigin，匿名和跨站请求不得触达上游。普通聊天、知识库与原有编辑器保持现有行为。首期不接外部消息渠道、不开放通用模型写入工具。

验收：模拟真实 Iris 附件／流式协议，证明生成前后博客条目和公开图片权限不变；点击保存后复用博客 API 验证草稿隔离及公开发布；错误、取消、越界内容和格式异常被处理；组件展示预览及明确确认动作。完成全套测试、类型检查、生产构建及可行的浏览器验收。独立 Iris 离线时不声称真实模型链路已验收。
