# 回收站

用户已批准：文章、日常和收藏先移入回收站，一键恢复原内容，彻底删除前确认，入口位于小屋工具。

保留 items 原记录，用 item_trash 标记移除时间；恢复仅撤销标记，保留原时间、照片、分类、标签、公开范围、草稿状态、留言和点赞。回收站仅站主可见。正常列表、详情、留言、点赞及公开统计不显示被移除的内容。照片仍被引用，清理未使用图片不会误删。

回收站页面沿用固定头部及奶油粉色主题，按移除时间分页展示，提供恢复、刷新和带确认框的彻底删除。彻底删除移除记录及关联留言、点赞；照片原件保留在资料柜，可以按现有流程清理。没有自动清空、过期删除或批量永久删除。

SQLite 和 Cloudflare D1 共用可重复执行的新增表及查询；完整备份包含回收站，迁移导出保留标记。已有内容保持原样。
