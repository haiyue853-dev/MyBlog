# Iris 聊天回答转博客

用户已在建议「回答下面整理成博客 → 选择文章或日常 → 预览修改 → 确认发布或保存草稿」后回复「开始」，本轮按该范围执行。

只有有文字、无错误且未在生成的 assistant 回答显示「整理成博客」。点击打开类型选择窗口，选择后原样带入现有 Editor，正文默认排版预览；不再请求模型重写，也不写数据库。标题取第一行标题或正文的前 40 字，可以在预览中修改。

候选保持 draft，图片初始为空，不将模型输出里的文件地址作为已授权图片。用户可以通过编辑器添加自己的配图。仅点击确认发布或保存草稿才调用现有站主写入接口，既有身份及来源校验不变。

关闭编辑器可从「继续预览聊天内容」重新打开；独立的标签页暂存键保存候选，与素材写作面板互不覆盖。编辑器已有草稿暂存与稳定候选 ID 重试逻辑继续复用。重新选择另一条回答会替换当前聊天预览，并在类型窗口提示。

验证正文保真、两种内容类型、无内容拒绝、失败和流式回复不提供入口、关闭重开、明确发布后才产生记录、保存草稿仅自己可见。只改博客，不修改 Iris 源码，不发布到云端。
