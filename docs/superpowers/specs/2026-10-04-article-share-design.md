# 文章分享卡片

用户已批准：文章底部的主题小浮层提供复制链接、生成并下载含封面／标题／摘要／二维码的分享图片，仅公开已发布文章开放。

入口与爱心同行，固定小屋头部沿用。浮层支持关闭、外侧点击和 Escape，手机宽度跟随正文。先生成 PNG 预览，再提供明确下载按钮。复制失败时显示可选中的链接；生成失败保留浮层供重试。公开状态在每次复制、生成、下载前通过原详情 API 重新确认，私密、草稿及回收站内容不分享。

使用当前访问地址的 origin 与文章 id 构成无查询参数／章节 hash 的链接。二维码由 qrcode 在浏览器本地编码，无外部二维码服务。原生 Canvas 排版 1080×1440 PNG，沿用奶油粉色、封面位置、站点名称、日期与阅读信息；无封面用主题图案，长标题和摘要按宽度分行并省略。图片和链接不写入数据库，不改变原记录；本地／内网链接提供简短上线后重新生成提示。

依赖仅 qrcode 及其类型定义；海报生成按需加载。验证公开范围、链接正确性、长文字、二维码可解码、下载 PNG、手机／桌面及关闭和刷新，不增加发布、收藏分享或可配置模板。

参考：[qrcode 官方文档](https://github.com/soldair/node-qrcode)。
