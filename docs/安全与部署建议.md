# 小屋安全与部署建议

核查日期：2026-10-02。范围：先只部署小屋，Iris 后续接入；当前尚未购买服务器或发布网站。

## 建议方案与费用

保持现有单实例 Next.js + SQLite + 私有附件目录，用 Linux 服务器运行 Docker Compose + Caddy。不另买数据库、对象存储或付费 SSL。2 核 2 GB、40 GB 系统盘适合作为低流量个人站的起点；这是基于当前架构的建议，尚未经过云端容量测试。随着私人文件增加，再看磁盘用量。

| 方案 | 公布价格与配置 | 判断 |
| --- | --- | --- |
| 腾讯云海外入门型（如东京、新加坡） | 30 元/月，2 核 2 GB，40 GB，20 Mbps，512 GB/月 | 在本次核查的同内存套餐中更便宜，按自己的常用网络先测访问速度 |
| 腾讯云香港入门型 | 38 元/月，2 核 2 GB，40 GB，20 Mbps，512 GB/月 | 优先考虑的香港省钱方案；官方明确不保证内地跨境公网质量，建议先月付试用 |
| 阿里云国际站轻量入门规格 | 4.5 美元/月，1 核 1 GB，20 GB，4 Mbps，1 TB/月；2 GB 规格为 9 美元/月 | 1 GB 可作为压成本候选，内存余量更少；地区实际库存、结算价需到购买页确认 |

腾讯价格、流量及网络说明来自 [官方价格总览](https://cloud.tencent.com/document/product/1207/73452//)；香港 38 元套餐也见 [调价公告](https://cloud.tencent.com/announce/detail/2131)。阿里价格来自 [国际站价格页](https://www.alibabacloud.com/en/product/swas/pricing?_p_lc=1)。以上为公开常规价格，不是账户专属优惠，也不声称是全市场最低。腾讯香港 2 GB 套餐不适用文档中的长期购买折扣；超出流量包另收费。

推荐先月付比较香港与东京/新加坡的实际访问速度，速度合适再长期购买。按香港 38 元常规月费计算，服务器约 456 元/年；域名续费、异地备份和流量超额另计。新用户首年优惠要同时看第二年续费价格。

不建议为了免费托管而把当前项目直接搬到纯静态平台：项目需要后端登录、可写 SQLite 和持久化私人附件。换平台需要改存储架构。已有长期在线设备可减少服务器租金，但仍有电费、网络与在线维护成本。

## 香港与备案

网站托管在香港节点通常无需工信部 **ICP 备案**，大陆节点对外提供网站服务需要办理。依据：[阿里云备案服务器 FAQ](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/server-check-faq)。

“无需 ICP”不等于所有手续都免除。阿里云目前的 [备案流程说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview) 将公安联网备案单独列出，并说明香港/海外网站在内地可访问时仍需办理；具体适用与办理资料，上线前向所在地公安网安部门确认。若以后接入大陆 CDN 或其他大陆接入服务，还需按其要求核实 ICP 条件。

## 本轮已落实的防护

- 密码 scrypt、会话令牌只存哈希、HttpOnly / SameSite / HTTPS Secure Cookie；重设密码撤销已有会话。
- 写入接口校验 `Origin`，私人条目和附件由后端授权；普通文件不会因上传而公开。
- 按受控 Caddy 提供的访问地址限制登录：10 次失败 / 15 分钟；30 次登录请求 / 分钟，读取正文前限制，读取后再次检查并发失败次数；正文不超过 8 KB。限流记录存 SQLite，重启保留，过期清理。
- Caddy 覆盖专用客户端 IP 头，Compose 不映射应用 3000 端口。直连本地默认不信任代理头；`TRUST_PROXY=1` 只用于受控反代环境。
- HTML 的 CSP 每请求生成随机 nonce，生产脚本不允许 `unsafe-inline` / `unsafe-eval`，阻止框架嵌套、对象加载和外部连接。现有主题色与裁剪位置需要行内样式，因此只对样式保留 `unsafe-inline`。实现参考 [Next.js 官方 CSP 指南](https://nextjs.org/docs/app/guides/content-security-policy)。
- HTML 和私人附件禁止缓存；附件保留更严格的 `default-src 'none'; sandbox`，非图片按下载处理。
- Docker 启动前只读验证 HTTPS 来源和已有账号；公开部署禁用网页初始化，避免空库抢注。应用以 node 用户运行，禁新增权限、移除 Linux 能力并限制进程数量。
- Caddy 自动 HTTPS、HSTS（不预加载、不扩展到所有子域名）与 22 MB 正文上限；浏览器禁用本站不需要的摄像头、麦克风、定位权限。
- Docker 构建上下文排除私人数据、备份、环境文件、截图和测试目录。
- 本次生产依赖审计 `npm audit --omit=dev --registry=https://registry.npmjs.org`：0 个已知漏洞。该结果只代表核查时的依赖公告，不代表所有攻击都能阻止。

## 上线时需要执行

1. 本地初始化账号，用现有备份工具迁移一致的数据库和附件；通过私有通道传输，不上传到公开仓库。
2. 按 README 配置域名、挂载与 UID 1000 权限，拉取最新 Caddy 镜像并启动 Compose。只开放 80/443；SSH 使用密钥并限制管理来源，3000/8000/2019 不对公网开放。Docker 的端口映射也需在云安全组检查。
3. 开启云账户多因素认证，安装系统安全更新。设置费用/流量提醒，避免无限额按量资源。
4. 验证真实 HTTPS、Secure Cookie、登录与登出、公开/私密权限、头像上传、20 MiB 文件上限、重启数据保留；演练从备份恢复。
5. 安排私有异地备份并验证恢复，按真实文件用量监控磁盘；定期复查依赖和镜像安全更新。

应用代码不能承担大流量 DDoS 清洗。可先评估 [Cloudflare 免费计划](https://www.cloudflare.com/plans/free/) 的基础 DDoS/CDN 防护；[官方说明](https://developers.cloudflare.com/ddos-protection/get-started/) 写明免费计划默认启用 DDoS 规则。接入前必须验证常用网络的访问速度，并完成源站限制与真实 IP 配置：默认 Caddy `{remote_host}` 会看到前置代理的地址，不能直接沿用为访客限流。仅信任官方代理地址段或使用受控隧道，避免伪造头和绕过源站。本轮没有接入任何外部防护服务。

本地自动化测试、生产构建和浏览器业务验收已覆盖这轮改动。当前机器未安装 Docker/Caddy，没有运行真实容器、申请证书、验证云防火墙或做公网压力测试。服务器安全配置、恢复与容量，需要购买后在真实环境验收；Iris 不计入当前最低配置。
