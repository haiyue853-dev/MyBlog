### 1.2 安全与账号

- 站主账号为单例，密码最短 **10** 位（`src/lib/types.ts` 的 `MIN_PASSWORD_LENGTH`）。
- 口令哈希 scrypt **N=32768**（Node 默认是 16384）；旧格式 `scrypt:salt:hash` 仍能验，首次成功登录会静默升级成新格式 `scrypt$N$r$p$salt$hash`。
- 登录失败阈值 **5** 次/15 分钟，超限进入**渐进封禁 15 → 30 → 60 分钟**，封禁等级在行上保留 24 小时。
- 会话 180 天且自动续期（剩余寿命过半才续），Cookie 为 `HttpOnly` + `SameSite=Lax`，HTTPS 下带 `Secure`。
- 写接口一律 `requireOwner`(401) + `requireOrigin`(403)；`listItems` 对路人只返回 `visibility='public'`。
- 线上 Worker 额外发 `Strict-Transport-Security`、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`。**本地与自建 Node 服务不发 HSTS**（该头只写在 `cloudflare/worker.ts`）。
- 云端登录架构：浏览器做 scrypt，Worker 只验 `sha256(scrypt 结果)`，Worker 拿不到明文口令。

### 1.3 图片处理（本轮新增）

| 项 | 说明 |
| --- | --- |
| 上传压缩 | `src/lib/image-optimize.ts`，浏览器端 Canvas 缩放 + WebP 编码，**长边 1600px、质量 0.82**。接入资料柜上传与记录配图；非图片自动跳过，GIF/SVG 按文件头魔数识别后跳过（避免动图丢帧、矢量转位图） |
| 头像 | `avatar-crop.tsx` 改为输出 512×512 WebP（原为 PNG） |
| 孤儿清理 | `GET /api/files?unused=1` 扫描、`POST /api/files?cleanup=1` 批量删；UI 在资料柜标题下「清理没用到的图片」，先列清单与可腾出空间、确认后才删。仅列出未关联头像或记录的图片，普通文档不进入清理范围；提交删除时重新扫描，已关联的自动跳过 |
| 长缓存 | 文件响应 `Cache-Control` 由 `private, no-store` 改为 `private, max-age=31536000, immutable`（文件 UUID 命名、内容不再变更） |
| 写盘失败回滚 | 上传写盘失败时同时收掉数据库行与磁盘文件，不再留下半个文件 |

实测：一张 2226×3000、6.39 MB 的 PNG 上传后变为 **157 KB**（省 97.6%），MIME 变 `image/webp`。

**存量文件不会自动变小** —— 只有重新上传才走压缩。当前 `data/files` 173 个文件共 **146.7 MB**（平均 868 KB/张），其中 125 张 PNG 占 125.2 MB；若反复换图而不清理，旧图会一直堆积，需定期用「清理没用到的图片」收一次。

技术栈：

- **数据库**：SQLite 系（本地 `node:sqlite` / 线上 D1），**手写 SQL，无 ORM**。会话、限流、统计全部自建（没有 NextAuth 等）。
- 运行时依赖只有 7 个：`@noble/hashes`、`lucide-react`、`next`、`react`、`react-dom`、`react-markdown`、`remark-gfm`。

本地：浏览器 → Next.js 同源 API → SQLite / 私有文件。
线上（Cloudflare，已决定不再更新）：浏览器 → Workers 同源 API → D1 / 私有 R2。

### 4.3 阿里云（计划中，尚未开始）

用户已确定后续部署到阿里云。要点：

- **ICP 备案是最耗时的一步**：大陆节点必须先备案才能开 80/443。服务器购买时长需 ≥3 个月才有备案服务码；域名要实名认证；审核通常 1~20 个工作日；**备案期间域名不能对外提供访问**（先不解析、用 IP 或临时端口调试，拿到备案号再上线）。
- 页面文案需保持无经营性表述（无价格、购买、付费、进群费等）——「剪辑素材」下线就是这个原因。
- **反代必须转发三个头**，否则会分别踩坑：`Host`（同源校验依据，缺了写操作全 403「请求来源不匹配」）、`X-Forwarded-Proto`（决定会话 Cookie 带不带 `Secure`）、`X-Forwarded-For`（登录限流的客户端标识）。
- 自建 Node 服务**不发 HSTS**，所以先用裸 HTTP 调试不会被浏览器强制跳 HTTPS；正式上线配好证书后再决定要不要加。
- 进程守护（systemd 或 pm2）与备份（`npm run backup` + 云盘快照）待安排。备份要走 `.backup`/`VACUUM INTO` 语义，**裸拷 `world.sqlite` 会漏掉 WAL 里的数据**。
