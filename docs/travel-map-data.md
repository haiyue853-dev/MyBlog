# 旅行地图数据

2026-10-05：按用户要求撤下旅行地图的页面展示和导航。以下记录保留实现与数据来源，组件、地理数据、地点接口及已保存足迹没有删除。

旅行足迹使用 cn-atlas 0.1.2 的省级与地级行政区数据（34 个省级区域、372 个地级区域）。原数据为未投影的 GeoJSON；仓库内 `src/lib/travel-geography.json` 已转换为省、市 SVG 轮廓、边界范围与城市中心坐标，浏览器不请求第三方地图服务。

- 数据来源：[cn-atlas](https://github.com/BarbarossaWang/cn-atlas)。包元数据标注作者 Amll、ISC 许可证；页面保留来源链接。
- 使用等积圆锥投影，SVG 尺寸为 960 × 630；轮廓按小于半个 SVG 像素的容差简化。南海诸岛保留在小图中，三沙标记使用相同的小图坐标。
- 地点以行政区代码区分，例如福建福州 `350100` 与江西抚州 `361000`，避免重名误亮。
- 地图支持 1–16 倍缩放、滚轮、拖动和双指操作；点省份或从主题菜单选省份自动定位各市，返回全国恢复初始视图。键盘聚焦地图后可用加减键缩放、方向键移动、Home 返回全国。
- 地点圆点和文字随地图缩放保持屏幕尺寸；相邻圆点按距离选择城市，拖动结束不触发城市选择。点击未到访市级区域可查看名称，站主可从手账中为该城市添加足迹。
- 旅行设置独立存于 SQLite／D1 的 `settings.travel`，完整备份与 Cloudflare 导出保留。关联记录的可见范围由现有内容规则决定，访客拿不到私人、草稿或回收站记录的关联 ID。
- 已按真实旅行记录加入福州（2026-04-04），并按站主提供的信息标记泉州为家乡、厦门为上大学的城市；未提供的日期保留为空。

如需重新生成，使用 d3-geo 3.1.1 与 cn-atlas 0.1.2；一次性生成工具及原始包位于本地忽略目录 `outputs/travel-map-tools`。正常开发、构建与运行只需要已生成的数据文件。
