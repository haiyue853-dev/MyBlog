# Iris 个人博客助手需求

记录日期：2026-10-06（北京时间）。博客侧的素材输入、预览、编辑与确认发布已实现；本机博客专用 Iris 实例已启动，真实模型的文档整理链路已验证。

最新交互：在“让 Iris 帮我写博客”中生成成功后自动弹出预览窗口，正文默认显示排版效果，用户可返回编辑、保存草稿或点击确认发布。关闭窗口仍可从页面重新打开；普通聊天不会自动发布内容。已用隔离测试数据验证该流程。

## 用户已明确的目标

- Iris 仅供站主本人使用。
- 普通聊天的“结合知识库”默认关闭，需要时由站主手动勾选。
- 博客将部署到已有阿里云 Windows 服务器；用户随后明确 ICP 备案仍在进行中，暂不开放公网网站。
- 用户把想发布的内容发给 Iris，由她协助整理并发到个人博客，作为个人助手。

## 建议的使用流程

用户发送文字、图片或资料，并说明“整理成日常”或“写成文章”；Iris 整理标题、正文与配图，通过博客工具保存内容。发布方式按用户选择执行，成功后返回博客链接；保存草稿时返回可继续编辑的入口。

发送素材本身不等于要求将全部素材公开。仅导入知识库、讨论或整理资料的消息，不应触发博客发布。

## 现有能力与需要接通的部分

- 博客已有站主权限、文章／日常写入、图片上传、草稿和发布状态，助手写入应复用现有内容校验与存储。
- 博客内 Iris 新增写博客面板及 `POST /api/iris/blog/prepare`。通过既有 Iris 会话附件和聊天接口整理素材，safe 工具集允许读取附件；普通聊天与知识库保持现有接口。
- 独立 Iris 的聊天模型支持 attachment_ids，并有工具及 MCP 扩展入口。存在企业微信与 NapCat 网关源码，但本轮未验证任何消息渠道的实际配置或可用性。
- 生成结果只含校验后的内容，博客不会自动执行模型写入。用户进入现有编辑器确认发布或保存草稿，显示真实保存结果与查看入口；错误不生成记录，编辑和候选预览在当前标签页可恢复，创建失败重试会核对已创建条目并保存当前修改。
- 博客内操作继续绑定站主会话；若接外部消息渠道，需要校验用户绑定身份，并使用受限的服务端写入凭据，不能只凭昵称或转发消息授权。
- 阿里云部署通过受控内网连接 Iris；独立 Iris 端口不直接对公网开放。

## 用户已选择

1. 发送入口：博客内 Iris 对话框。
2. 发布方式：先预览，用户确认后发布。
3. 实现位置：仅增加博客网页功能，不修改 Iris 源码。

2026-10-07 补充：普通聊天完整回答下面也有「整理成博客」入口。用户进一步要求标题等字段全部拟定好，因此选择文章或日常记录后会请求 Iris 重新拟定标题、正文、分类、标签和文章摘要，去掉对话开场、工具过程说明和追问，再打开预览。不能直接用第一句话充当标题，也不能在模型失败时悄悄退回原文搬运。可停止整理，失败与取消保留上一份候选。可以改文字、配图和可见范围；只有站主点击确认发布或保存草稿才写入博客。关闭后可继续预览，候选和修改在当前标签页可恢复。未完成或出错的回答不提供入口。已有旧预览需重新点击整理入口生成。

普通聊天随后接入 Iris 既有 research 工具，允许站主读取公开网页，再将回答整理成博客。知识库开关与网页读取独立，仍默认关闭。网页不能核实时应如实说明；GitHub 主站连接超时，官方公开 API 的真实读取已验证。素材面板保持 safe 工具组；不开放命令执行、浏览器点击或自动发布。

首期通过 Iris 现有接口生成内容，博客负责素材上传、预览、编辑与发布。设计见 docs/superpowers/specs/2026-10-06-iris-blog-assistant-design.md；实现过程中不得将未验证能力标为完成。

## 交付验证

博客助手首轮全套 246 项测试通过，隔离生产网页验证文档／图片上传、生成预览时匿名列表不变、修改后确认发布文章、保存日常草稿、未公开图片返回 401，以及刷新恢复未保存的编辑。390px 手机布局没有横向溢出。

随后按 Windows 服务器补充部署材料；当前 247 项 Node 测试及 4 项 Python 部署测试通过。隔离复制后的真实 Iris API 已验证文档提取、safe/read_attachment 工具、JSON 流式结果和重启会话保留，模型端仍为本地模拟接口。新增全面编辑权限矩阵，匿名、伪造、过期、撤销会话均被拒绝。未修改独立 Iris 源码、正式内容或部署阿里云；真实模型和云端服务／HTTPS 仍待验收。部署步骤见 [Windows 教程](阿里云Windows部署.md)。

用户随后要求试运行本地 Iris：读取原有当前模型配置，在仅监听 127.0.0.1:8000 的博客专用独立副本中使用真实 mimo-v2.5 模型，发送虚构 Markdown 素材，通过博客 files/iris 接口生成“雨后散步的二十分钟”预览，耗时约 29 秒。健康与站主权限检查通过，测试数据库记录数保持 0，素材未公开。证据 outputs/real-iris-blog-smoke.log；服务保持后台运行，原 Iris 源码、历史数据及正式博客内容未改。云端 Windows 服务与 HTTPS 仍待备案通过后验收。
